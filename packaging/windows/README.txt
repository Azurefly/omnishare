OmniShare v__VERSION__ Windows 安装包

1. 解压后可双击 start-omnishare.cmd 直接启动；该文件会调用同目录的 start-omnishare.ps1。
2. 也可运行 install.ps1 完成用户级安装。
3. 数据默认保存在 %APPDATA%\OmniShare，卸载程序不会删除用户数据。
4. 新安装默认开启局域网（0.0.0.0）和设备自动发现，密钥保护默认关闭。可在设置中自行开启并设置任意非空密钥，无长度及字符类型要求；不需要初始化 Token。关闭保护后可连接本机的设备能读取、修改、删除内容和配置，请勿暴露到公网。升级保留已有网络与密钥设置。
5. 安装包尚未代码签名，Windows 可能显示安全提示。
