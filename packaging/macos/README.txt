OmniShare v__VERSION__ macOS

需要 macOS 12 Monterey 或更新版本。Apple 芯片选择 arm64，Intel 选择 amd64。
DMG：打开映像，将 OmniShare.app 拖入 Applications，推出映像后从应用程序启动。
ZIP：用 Finder 解压，将完整 OmniShare.app 复制到 Applications 后启动。
本包由 Swift/AppKit 原生启动器管理随包 Go 后端，服务就绪后打开默认浏览器。
应用菜单和菜单栏中的 OmniShare 菜单提供“打开 OmniShare”和“退出 OmniShare”。
应用在前台时可按 Cmd+O 打开工作区、Cmd+Q 正常退出；关闭浏览器标签页不会退出后端。
运行中再次打开应用会复用后端；退出后重新打开应用会继续使用原数据。
正常退出会让 Go 后端通过私有控制管道 EOF 完成请求收尾和数据写入。
数据默认位于 ~/.omnishare，也可以通过 OMNISHARE_DATA_DIR 指定目录。
自动选择的端口被占用时会寻找并保存可用端口；显式指定的端口保持不变。
更新前正常退出旧应用及后端并备份数据；替换整个应用，不要合并新旧应用内部文件。
无需手工运行应用内部的后端，也不要在下载后自行重新签名包内文件。
