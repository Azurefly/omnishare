配置公开交付

已有独立领取站时，向管理员索取领取地址、管理连接方式、发布设备名和发布密钥。

收件人能访问的 HTTPS 根地址。填写到域名或 IP（可带端口）为止。
SSH 转发用本机的 http://127.0.0.1:18485。若管理员提供了私有 HTTPS 管理地址，填入该地址。
填写管理员给此设备登记的名称，需与服务器上的名称完全一致。
填管理员发给你的 64 位小写十六进制原密钥。已保存配置且其余三项没改时可留空。
如何启动 SSH 隧道

在本机 PowerShell 执行。将登录用户和 SSH 主机改成管理员提供的值。

ssh -N -o ExitOnForwardFailure=yes -L 127.0.0.1:18485:127.0.0.1:18485 DEPLOY_USER@DELIVERY_HOST

使用指定私钥时加上 -i "C:\路径\私钥文件"。先向管理员核对主机指纹。SSH 运行后可回到应用，保持终端打开。

保存后在「公开交付」点「刷新」。看到「交付列表已刷新」后，就可以从文件、随手记或协同文档发起交付。

清空公网领取地址并保存会停用本机的交付功能。需要作废已发链接时，请先逐条撤销。
