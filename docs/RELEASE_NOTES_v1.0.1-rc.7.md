# OmniShare v1.0.1-rc.7

- 通过 Wi‑Fi 或 Tailscale 再次添加同一设备时，OmniShare 会验证双方的连接和设备身份，将可用地址合并到原来的设备，并保留本地别名。重启后仍可使用这些地址。
- 两台设备在同一 Wi‑Fi 下时，可通过 Tailscale 发起连接，经已核实属于同一设备的局域网地址回连。两端都升级后，若全部回连失败，绑定窗口会逐项显示对方实际尝试的地址及原因。
- 文件列表和回收站标明快捷方式、文件库副本及来源设备。「文件 → 清理当前设备」可筛选源文件不可用的快捷方式和库内副本，勾选后移入回收站。清理快捷方式保留外部原件。存储统计按库内文件内容去重，包含回收站中的副本。
- 工作台导航、侧栏和弹窗采用液态玻璃风格，支持深浅主题、减少透明度和高对比度。文件内容和编辑区使用实色阅读背景。

建议两台设备同时升级以取得完整的绑定诊断。此候选版提供 Windows、Linux 和 macOS 安装包。macOS 通用 DMG 支持 Intel 和 Apple Silicon，使用临时签名，尚未经过 Apple 公证。
