# 安全共享与使用边界

本文说明 OmniShare `0.1.1` 的内容发送、设备连接、会话及备份行为。OmniShare 是自托管内容工作区，内容保存在当前节点，由获准访问该节点的用户使用。

## 发送目标与设备状态

设备区按当前节点、在线和离线组织。在线状态来自现有健康检查或发现结果，不能据此判断对方已经获得授权，也不代表双方完成可信配对。

点击其他节点会打开独立页面，该节点需要自己的访问密钥或初始化流程。设备链接只接受纯 HTTP/HTTPS origin，拒绝用户名密码、路径、查询参数、片段和相对地址；新页面使用 `noopener noreferrer` 与 `no-referrer`。当前管理密钥不会被添加到设备链接，数据请求使用当前节点的相对 API 路径。

设备名称、地址与错误消息按文本呈现。发现节点本身不会触发内容发送，不会赋予其他节点当前工作区的管理权限。

## 剪贴板先预览，再确认

1. 用户点击“从剪贴板发送”后，页面才请求浏览器剪贴板读取权限。
2. 确认框显示读取到的纯文本或 PNG、类型和大小、目标节点的真实 origin，以及保留时长。
3. 用户确认后，文本保存为随手记，PNG 进入普通文件上传队列。
4. 取消、关闭或读取被拒绝时，不发送内容；关闭预览会清空文本、文件引用与本地 Blob URL。

保留时长默认 24 小时，可选择 1 小时或 7 天。不会轮询、后台监控或自动同步剪贴板，预览也不写入浏览器长期存储。浏览器通常要求 HTTPS 或本机地址才允许读取；不支持时可继续手动粘贴文本或选择文件。

### 类型与资源限制

支持 `navigator.clipboard.read()` 时优先选择 PNG，否则选择纯文本；仅支持 `readText()` 时使用文本。读取权限被拒绝后，不通过另一条路径再次隐式尝试。

- 纯文本最多 256 KB，发送前还会检查序列化 JSON 不超过后端的 1 MB 请求上限。
- PNG 最多 16 MB，并受节点文件上传上限约束。预览前检查签名与 IHDR，单边不超过 8192 像素，总像素不超过 16 × 1024 × 1024；浏览器实际解码成功后才开放确认。
- HTML、SVG 和其他富内容不作为活动页面导入；文本通过纯文本值展示，图片通过本地 Blob URL 预览。

确认操作有防重复提交状态。失败会显示行内错误，不自动重复创建内容。图片确认后也遵守文件队列的并发限制。

## 传输状态、取消与重试

文件任务进入队列后立即可见，依次显示排队、上传和服务端处理；服务端成功响应后才标记完成。请求体已经发送完毕不代表服务器已经保存成功。

所有上传尝试共享最多 3 个并发名额。排队任务可以取消且不发出请求；进行中的任务取消时终止当前连接，迟到回调不能把取消状态改回完成。失败或取消后的手动重试重新排队，不绕过并发限制。

**取消和连接中断不能召回已经到达服务器的数据。** 即使浏览器没收到成功响应，服务器也可能已经保存文件或文本。重试前应检查对应列表，避免重复创建逻辑内容。清理已结束任务只移除页面队列记录并释放文件引用，不删除节点上已经保存的文件。

队列和预览只属于当前页面，刷新后不会自动恢复或重新发送。上传使用流式单请求，尚不支持分片断点续传；下载与视频播放支持 HTTP Range。

## 会话、访问与草稿

首次启动默认仅监听回环地址。未设置访问密钥时，管理和数据接口要求正确的本机初始化令牌。启用局域网访问前必须设置至少 16 字节的访问密钥；服务器保存 PBKDF2-HMAC-SHA256 派生值，管理密钥不通过 URL 传递。

浏览器中的访问密钥和初始化令牌仅保存在会话存储；会话存储不可用时使用当前页面内存，重载后需要重新验证。文档保存失败或冲突时保留最新草稿，草稿也是会话级数据，内存回退时不会跨页面重载保留。

下载、视频及 Raw 内容使用短时内容票据。HTML、SVG、XML 等主动内容强制下载，页面使用 CSP 与 Referrer 限制。Service Worker 只缓存固定静态资源，不缓存管理接口或用户内容。

当前使用单管理员密钥，没有只读、上传者或审计员等角色。公开网络部署应自行配置 HTTPS 或可信 VPN。设备发现的签名身份有助于校验公告，但不替代用户授权与对端身份确认。

## 备份、恢复与审计

应用版本 `0.1.1` 与备份格式版本相互独立。新加密备份仍使用 v3 `.osb`，支持恢复 v3、v2 与明文 ZIP；版本号重置不会将数据或备份格式降级。

v3 认证完整包头、分块顺序和结束记录，并拒绝截断与尾随数据。包头中的版本、算法、创建时间及校验清单仍是可读元数据，数据内容经过加密。v2 保留旧格式的分块校验，不具有 v3 的完整包头及结束记录认证。ZIP 内容不加密。加密口令不写入数据目录，丢失后无法恢复对应加密包。

恢复先在暂存目录解压校验，再切换状态、配置与文件；成功恢复会替换当前数据，包括备份之后新增的内容。操作前应导出当前备份并暂停内容写入。失败时回滚到最终切换之前的状态，恢复上传有空闲超时与防重复提交处理。

审计哈希链用于检查链内一致性，不能代替独立可信存储或外部签名，也不代表拥有主机写权限的人员无法修改记录。SQLite 按配置裁剪审计，JSON 回退引擎不执行该裁剪。

## 当前能力边界

- 内容通过当前节点共享，不提供系统键鼠控制、输入监听、音频共享或后台剪贴板同步。
- 当前没有接收方身份绑定的设备配对、逐设备发送/接收权限、接收审批或端到端加密传输。
- 若后续增加直接配对，需要明确设备身份、双方确认、授权范围、到期与撤销、接收同意和会话重放防护；设备在线或组成员身份不自动获得内容管理权限。
- 清除访问密钥或恢复无密钥配置后的初始化令牌续发尚待完善，可能需要重启后使用新的本机初始化链接。自动清理与恢复的文件协调、审计锚点在备份中的完整保留仍需后续改进。
- 文档采用版本冲突检测，尚不支持 CRDT/OT 逐字实时合并。普通阅读和下载计数批量落库，进程崩溃可能丢失最近几秒计数。

## 验证入口

```bash
npm --prefix frontend run check
npm --prefix frontend test
npm --prefix frontend run build
npm --prefix frontend ci --ignore-scripts
(cd frontend && npx --no-install playwright install --with-deps chromium)
npm --prefix frontend run test:browser
```

前端测试覆盖确认前无请求、取消清理、迟到结果、重复提交、类型与大小限制、重试并发和错误反馈。真实 Chromium 检查使用合成 API 数据验证 HTML/CSS/JS、明暗主题、导航、设置、剪贴板、上传与多种屏宽，并保存截图；后端鉴权与持久化由 Go 和独立 HTTP 进程测试覆盖。

这些检查不替代 Windows 托盘、macOS 权限、Safari 或所有触屏设备的真机验收。发布与迁移方式见 [0.1.1 发布说明](RELEASE_NOTES_v0.1.1.md)。
