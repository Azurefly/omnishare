# 局域网访问与自动发现调整

本轮源码提交：`2b4909b213e54486f24cb46820643746908c7eaa`。这些改动位于 PR #33，尚未进入公开版 v0.1.1，不代表三平台安装验收或 Apple 公证已经完成。

## 使用行为

新安装默认开启局域网，监听 `0.0.0.0`，访问密钥保护默认关闭。浏览器和桌面仍可通过本机地址打开；同网可达设备可直接访问，无需初始化 Token，也不需要先设置访问密钥。

设置中的“访问密钥保护”是独立开关。开启时自行填写任意非空密钥，不规定最小长度或字符组合，中文、数字、符号和空格原样处理；`CLEAR` 与 `__KEEP__` 也可作为普通密钥。关闭后立即停止密钥校验；已设置的密钥保留，重新开启时可留空继续使用。开启保护但尚未设置密钥时，界面只提示填写或关闭开关，不能将一个空密钥冒充已开启保护。

升级不擅自关闭原有保护，也不覆盖原有网络设置。已安装旧版的用户可在设置中关闭密钥保护、开启局域网并保存。密钥开关立即生效；监听地址和局域网设置需重启服务。不要删除数据目录来套用新默认值。

不再生成、读取或校验初始化 Token；旧 Token 文件条目在启动时移除，不再通过 URL 或桌面导航传递。

## 设备自动发现

启动后在活动 IPv4 组播网卡上自动发现其他 OmniShare 实例，不需要手工输入 IP、配对或共享访问密钥。约每 3 秒发送公告并重新检查网卡，界面约每 5 秒刷新设备列表。网络切换后会重试，过期设备会移出发现列表。HTTP 公告保持旧协议兼容，HTTPS 公告包含签名绑定的协议字段，链接不再错误地固定为 HTTP。

发现设备与访问设备相互独立：对方开启密钥时，打开其工作区仍遵循对方的开关；不会把本节点的密钥传给对方。后台保留公告身份、大小和时效检查，这些不需要用户操作，不属于首次访问验证。

自动发现依赖网卡及网络允许 IPv4 组播 `239.255.42.99:48281/UDP`。路由器客户端隔离、防火墙或系统局域网权限拒绝可能阻断发现或连接；程序不会关闭系统安全机制，也不保证跨 VLAN 自动发现。手动添加地址仍保留。

## 开放模式的边界

关闭密钥不是只读共享：能连到服务的设备可读取、修改、删除内容并修改配置。`0.0.0.0` 表示全部 IPv4 接口，不是自动识别可信网段；请勿将免密服务映射到公网。CORS、Host 检查、路径校验和备份完整性保护继续保留，不增加初始化验证步骤。
