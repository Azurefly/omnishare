# OmniShare v1.0.1-rc.6

- 跨设备转移文件时，工作台会等到服务端完成校验并返回结果。慢速连接可以超过原来的 8 秒，保留原有的服务端超时、来源清理和重试保护。
- 发布带附件的公开交付时，界面等待上传完成，预览和撤销也采用与服务端对应的等待时间。
- 在「设备与网络 → 当前设备 → 连接详情」可复制这台设备实际公布的局域网或 Tailscale 地址。手动刷新会立即重新探测，较早的自动刷新结果不会覆盖新结果。
- 两台设备的时钟相差一分钟内仍可通过局域网发现、双向绑定并读取共享内容。时差超过一分钟时，绑定窗口会提示检查系统时间。
- 在「设置 → 导出备份」可以选择普通 ZIP 或口令加密的 OSB。加密口令支持中文和首尾空格，旧版浏览器创建的备份仍可恢复。
- 目录计数随层级汇总，目录较多时能更快展示结果。工作区断线重开后可以加载已缓存的界面，重连时保留打开的编辑器。
- 桌面启动时会核实本机端口上的服务身份。如果常用端口被其他应用占用，OmniShare 可以继续选择可用端口。

本次为候选版。macOS 安装包支持 Apple Silicon 和 Intel，使用临时签名，尚未经过 Apple 公证。
