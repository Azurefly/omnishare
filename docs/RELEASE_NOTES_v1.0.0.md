# OmniShare v1.0.0

OmniShare 的首个源码版本。应用提供跨设备工作区、随手记、文件与视频、协同文档、安全分享、回收站和备份恢复。

- 设备绑定后聚合内容索引，编辑保存到来源设备，文件按需读取。
- 随手记支持 Markdown，协同编辑保留冲突草稿。
- 分享支持有效期、次数限制、撤销以及剪贴板受限时手动复制。
- 支持在 Windows、Linux 和 macOS 上从源码构建。GitHub Release 提供源码归档。

运行步骤和界面预览见 [README](https://github.com/Azurefly/omnishare/blob/v1.0.0/README.md)。
