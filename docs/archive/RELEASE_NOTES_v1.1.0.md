# OmniShare v1.1.0 发布说明

## 版本定位

v1.1.0 是从“可演示原型”转向“可离线构建、可安装、可验证”的产品基线版本。

## 主要新增

- 零外部依赖 Go 后端与原子 JSON 存储。
- 全新响应式工作台、PWA 安装与移动端适配。
- 随手记搜索、标签、编辑、置顶、TTL、阅后即焚。
- 文件搜索、分类、上传进度、SHA-256、Range 视频播放、TTL。
- 协同文档自动保存与版本冲突保护。
- 统计看板、活动审计、ZIP 全量备份、自动清理。
- 访问密钥、局域网多播发现、Tailscale 地址识别与手动节点。
- Windows、Linux、macOS 双架构构建及安装包。
- 五轮自动化测试脚本和正式测试报告。

## 破坏性变化

- 运行存储由旧 SQLite 原型切换为 `omnishare.json + uploads/`。旧 SQLite 数据不会自动迁移。
- 移除了 Gin、SQLite、WebSocket、Vue、Vite 等运行/构建依赖，旧的实时 WebSocket 编辑模型改为自动保存与版本冲突保护。
- 默认数据目录改为用户主目录下 `.omnishare`，不再写入源码目录。

## 升级建议

旧版本仍有有效数据时，先保留原始 ZIP 和 `backend/data` 目录。v1.1.0 首次启动使用新目录，不会覆盖旧数据库。需要迁移旧数据时，应另行编写 SQLite 到 JSON 的迁移工具，不建议直接替换文件。
