# OmniShare v1.1.0 五轮测试与验收报告

- 测试日期：2026-08-01
- 测试对象：OmniShare v1.1.0 完整源码与六平台发布产物
- 测试环境：Linux x86_64 沙箱、Go、Node.js、系统压缩与软件包工具
- 总结论：**五轮统一测试全部通过；最终补充端到端真实性核验通过。**

## 一、验收边界

本次在 Linux 环境中完成真实构建、真实服务启动、API 调用、双节点发现、Linux 安装与卸载以及软件包解析。

Windows 与 macOS 产物完成了对应架构的交叉编译、二进制格式识别、安装包目录与脚本检查；受当前环境限制，未在实体 Windows/macOS 机器上执行图形化安装和系统签名验证。因此，不将“实体机安装成功”作为已完成事项宣称。

## 二、第一轮：源码质量与可构建性

**结果：通过。**

验证内容：

- Go 源码格式化、静态检查和全量编译。
- JavaScript 语法检查。
- 前端零依赖构建脚本可运行。
- 清理旧 EXE、运行数据库、WAL、上传样例、`node_modules` 和历史构建缓存。
- 修复原项目 `StartRegister` 调用与函数签名不一致导致的编译阻断。

## 三、第二轮：存储与配置单元测试

**结果：通过，6 项核心测试全部通过。**

覆盖内容：

- 随手记创建、编辑、查询、标签与搜索。
- 阅后即焚、最大读取次数和生命周期处理。
- 文件、文档、统计及版本冲突。
- 过期数据清理。
- 配置持久化。
- 手动节点地址清洗与去重。

## 四、第三轮：API 集成测试

**结果：通过，4 组集成测试全部通过。**

覆盖内容：

- 健康检查、嵌入式前端与随手记 CRUD。
- 访问密钥拒绝与授权。
- 文件上传、HTTP Range 下载、删除和 ZIP 备份。
- 文档版本冲突、设备列表与节点接口。

## 五、第四轮：前端契约与跨平台构建

**结果：通过。**

验证内容：

- 前端生产资源生成并嵌入 Go 二进制。
- 页面关键功能、API 地址和 PWA 资源契约检查。
- 成功生成以下六个目标二进制：
  - Windows x86_64
  - Windows ARM64
  - Linux x86_64
  - Linux ARM64
  - macOS Intel
  - macOS Apple Silicon
- 使用系统文件识别确认产物分别为 PE32+、ELF 64-bit 和 Mach-O 64-bit 对应架构格式。

## 六、第五轮：真实端到端与安装包校验

**结果：通过。**

真实运行验证：

- 启动服务并加载内嵌前端。
- 同时启动两个节点，完成局域网 UDP 多播发现。
- 创建随手记。
- 上传文件。
- 使用 Range 请求读取指定字节片段，返回内容正确。
- 生成并打开完整备份 ZIP。
- 验证访问密钥未提供时被拒绝、提供正确密钥时放行。
- 在临时用户目录完成 Linux 用户级安装、启动与卸载。

安装包验证：

- Windows x86_64/ARM64 ZIP 结构完整。
- Linux x86_64/ARM64 TAR.GZ 结构完整。
- Linux x86_64/ARM64 DEB 可解析。
- macOS Intel/Apple Silicon `.app` ZIP 结构与 `Info.plist` 可解析。
- Windows PowerShell、CMD 和说明文件验证为 UTF-8 BOM + CRLF。

## 七、测试中发现并处理的问题

1. 原始 Go 源码无法编译：已修复并重构依赖边界。
2. 原始前端依赖 Windows 版 `node_modules`：已改为零依赖静态构建。
3. 原始说明文档存在超前描述：已归档并重新标注真实交付边界。
4. 原始源码包夹带数据库、上传数据和旧二进制：已清理并实现源码/运行数据分离。
5. 初次统一脚本在重复编译与压缩六平台包时超过执行窗口：已拆分“编译”和“打包”，最终统一五轮脚本完整通过。

## 八、遗留限制与发布风险

- 旧版 SQLite 数据不会自动迁移到新的 JSON 存储；升级前必须保留旧数据目录。
- 当前多人文档采用自动保存和乐观版本冲突保护，不是 CRDT/OT 实时协同。
- 尚未实现真正的分片上传、断点续传、秒传去重、视频转码和缩略图。
- Windows/macOS 安装包未进行商业代码签名，首次启动可能出现系统安全提示。
- Windows/macOS 仍需在目标实体机上进行最终安装冒烟测试后，才适合对外正式发布。

## 九、最终结论

OmniShare v1.1.0 已达到“源码可复现、核心业务闭环可用、Linux 可真实安装运行、六平台产物可构建、五轮自动化测试可重复执行”的内部测试版交付标准。

它还不是具备签名、自动升级、旧数据迁移和高级协同能力的商业正式版。建议将本版本作为后续 v1.2 增量开发和实体机验收的稳定基线。
