# OmniShare v1.2.0 发布说明

## 版本主题

**数据可恢复，分享可控制，发布可追溯。**

## 新增

- 随手记、文件、协同文档统一回收站。
- 随手记标准详情 API，补齐 REST CRUD。
- 恢复、单项永久删除、清空回收站。
- 可配置回收站保留天数，后台自动清理。
- 对象级安全分享链接。
- 分享有效期、最大访问次数、撤销和访问审计。
- 文件 SHA-256 重复检测和实体复用。
- 文件重命名。
- 看板增加有效分享和回收站数量。
- 安全分享与回收站独立工作区。
- GitHub Actions CI 和多平台构建工作流。

## 行为变化

- 普通删除不再立即删除实体，而是移入回收站。
- 阅后即焚和最大读取次数仍是永久销毁，不进入回收站。
- 过期内容先进入回收站，再按回收站保留周期永久清理。
- 备份包含活动数据、回收站元数据和仍保留的文件实体。
- 重复上传返回 HTTP 200 和已有文件对象；新文件上传仍返回 HTTP 201。

## 兼容性

v1.1.0 的 JSON 数据可直接读取。新增字段缺失时使用默认值：

- `deleted_at`: 未删除；
- `shares`: 空数组；
- `trash_retention_days`: 30 天。

## 已知限制

- 分享链接尚不支持独立密码和二维码。
- 分享能力令牌一旦泄露，在撤销/到期前可被任何获得者访问。
- 大文件仍是单请求上传，尚无分片与断点续传。
- 文档尚无版本历史，仅有版本冲突保护。
- Windows/macOS 安装包未签名。
