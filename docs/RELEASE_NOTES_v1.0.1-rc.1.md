# OmniShare v1.0.1-rc.1

本次候选版改进随手记和协同文档的 Markdown 写作体验。

- 两处共用编辑器，提供格式工具、写作／分栏／预览、字符统计、保存快捷键和铺满当前窗口。
- 小窗口优先显示正文，格式工具按需展开。协同文档的目录可以从顶部打开，底部保留保存操作。
- Windows 主窗口启动时适配显示器可用区域，避免任务栏挡住编辑器底部按钮。
- 关闭有改动的随手记时可以选择继续编辑或放弃修改。新建随手记的保留时长按每篇笔记重新设置。
- 协同文档继续保存到内容所属设备。遇到版本冲突时可保留本地草稿或另存副本。

桌面候选安装包供试用。下载后可根据发布附件中的 SHA256SUMS.txt 核对文件。
