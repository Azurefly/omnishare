# OmniShare v1.3 产品需求基线

## 1. 产品阶段

v1.3.0-rc1 的目标不是继续堆功能，而是把 v1.2 的演示闭环改造成“默认不暴露、失败不撒谎、删除可追踪、备份可恢复、发布可验证”的候选版本。

## 2. 发布门禁

| ID | 门禁 | RC 验收状态 |
|---|---|---|
| G-01 | 默认仅回环监听 | 已通过 |
| G-02 | LAN 必须配置强密钥 | 已通过 |
| G-03 | 管理密钥不进入 URL、长期浏览器存储或明文配置 | 已通过 |
| G-04 | 恶意 Origin 和 Host 被拒绝 | 已通过 |
| G-05 | 主动内容不能同源内联 | 已通过 |
| G-06 | Service Worker 不缓存用户内容 | 已通过 |
| G-07 | 写盘失败不改变已发布内存状态 | 已通过 |
| G-08 | 同数据目录只允许一个写实例 | 已通过 |
| G-09 | 分享 HEAD/Range/会话计数语义一致 | 已通过 |
| G-10 | Blob 缺失不会返回虚假去重成功 | 已通过 |
| G-11 | 备份包含状态、配置、文件摘要并可恢复 | 已通过 |
| G-12 | 六目标二进制和八类安装包结构可验证 | 已通过 |
| G-13 | 每轮重复核心回归 | 已通过 |
| G-14 | SQLite WAL 存储 | **未完成，阻止 GA** |

| G-16 | Windows/macOS 实机安装测试与签名 | **未完成，阻止商业正式发布** |

## 3. 下一阶段优先级

### P0：GA 前必须完成

1. SQLite WAL 存储适配器、迁移工具和回滚方案。
2. 数据库级事务、索引、分页游标和审计归档。
3. 管理员、只读、上传者、审计员与作用域令牌。
4. 分享密码或接收者验证，设备级撤销。
5. 自动 TLS/可信设备配对或明确的安全隧道引导。
6. Windows/macOS 实机安装、升级、卸载、休眠唤醒和防火墙测试。
7. 覆盖 `main`、桌面启动、Service Worker 行为和恢复中断的自动化。
8. SBOM、签名、公证、来源证明与依赖/工具链锁定。

### P1：正式产品竞争力

- 分片、暂停、重试和断点续传。
- 文件夹上传、批量下载、预览与配额预警。
- 文档版本历史、差异比较与人工合并。
- 可信设备剪贴板推送和收件确认。
- 原生托盘、开机启动、系统分享/右键发送。
- IPv6/mDNS 与网络诊断向导。

### P2：规模与生态

- CRDT/OT 实时协作。
- 对象存储和多节点复制。
- 团队空间、策略与合规保留。
- 插件、Webhook、CLI/API Token。
