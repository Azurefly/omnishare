# OmniShare v0.2.0-rc.1 · 统一工作区

这是候选版本。程序和安装器的内部版本已升级，不再复用旧 0.1.1 二进制。下载前请查看下方平台验证边界；macOS 尚未完成 Developer ID 签名与 Apple 公证，不能保证下载后直接放行。

## 本次变化

### 绑定一次，两端统一使用

在“添加设备并合并工作区”填写另一台设备的内网或 Tailscale 地址及实际 OmniShare 端口。对方开启密钥保护时才填写对方密钥。双方会自动登记，重复添加更新同一设备，不需两边分别配置。

工作台、随手记、文件与视频、协同文档、分享、回收站、活动记录默认合并所有直接绑定设备的数据。搜索、分页与统计在合并范围生效，每项内容标注来源；在当前窗口即可查看、编辑、下载、分享、恢复或删除，不必打开另一套应用界面。文件下载与视频转发保留 Range 支持。新建内容默认保存在当前接入设备。

数据仍保存在所属机器，不复制数据库、不重复复制文件。操作按“设备 ID + 对象 ID”写回原设备，同名内容不会被错误覆盖。机器端口、数据目录、访问密钥、备份与恢复仍作用于当前设备，不混合设备配置。备份不包含其他设备的数据或设备绑定关系。

旧版显式添加的地址会尝试升级成双向绑定；对方未升级、无法反向访问或启用了密钥时，界面保留设备并提示重新绑定，不假报成功。两端均需升级到本版才能使用新协作协议。

### 内网与 Tailscale

同一个设备 ID 可以具有多条内网／Tailscale 地址。连接前验证身份，避免把不同 IP 当成重复设备；已验证路由优先使用，局域网重新发现可以补充变化后的地址。不再优先展示 `198.18.0.0/15` 基准测试／代理虚拟地址。

局域网使用组播发现；Tailscale 通过本机客户端的 `tailscale status --json` 读取可见在线设备，不要求管理 API Key，也不扫描整个网段。自动探测限于最多 32 个可见在线设备、当前服务端口及 8081–8085；HTTPS 或其他端口请手动填写地址。支持 macOS 客户端 CLI 路径及 Windows 无控制台状态查询。客户端未运行、无读取权限、服务不可达和身份变化会有提示。

自动发现不等于绑定授权。Tailscale ACL、系统防火墙、客户端隔离和 macOS 局域网权限仍可能影响连接；应用不修改这些系统保护。

### 协同文档

新建文档改为应用内表单，不再依赖 `window.prompt()`，并提供创建中、错误及重复点击保护。修复 Mac WebView 中原生输入框不可用时“点了没反应”的交互路径。

前台工作区约每 2 秒检查更新，切回窗口时立即刷新；远端保存后，当前打开且未编辑的文档自动更新。正在输入、等待保存或有未保存草稿时，远端更新不会覆盖编辑器。版本冲突保留会话草稿，并提供“载入远端版本”和“草稿另存副本”。这是版本化保存与及时刷新，不是字符级 CRDT 同步。

### 故障与安全边界

- 设备离线不会阻断整个工作区；已取得的列表快照最多保留 15 分钟并明确标记，未取得的数据不会伪装成最新结果。快照只在进程内存中，不是离线文件副本；重启后需重新取得。
- 写入失败不盲目自动重试，以免重复创建或重复删除。离线设备上的原文件不可读写时明确报错。
- 首次绑定的对方访问密钥只用于该次请求，不保存到绑定文件。设备间使用身份签名、时间窗口、随机数防重放，绑定授权仅覆盖内容操作，不允许修改对方配置、下载备份或递归访问对方绑定的第三台设备。
- 连接限制为 LAN／Tailscale 地址，DNS 结果在拨号前校验并固定，不通过环境 HTTP 代理，不跟随携带身份的重定向；不关闭 HTTPS 证书校验。
- **免密开启的本机也会开放其合并工作区。** 能访问此实例的人可能读写全部直接绑定设备的内容。仅绑定可信机器，不要将免密实例映射到公网；不可信局域网请使用 HTTPS 或 Tailscale。HTTP 局域网传输本身并不加密。
- 解绑立即撤销本机对对方的授权，并尝试通知对方；对方离线时会明确告知反向登记尚未移除。
- 单源聚合最多 10,000 项或 4 MiB 列表数据，达到边界会标记不完整；绑定上限 32 台，缓存有全局容量限制。

## 下载与升级

Windows x64 使用 EXE 或 MSI；Ubuntu x64 使用 DEB，Linux x64 另提供 AppImage。macOS 12+ 提供 Universal DMG（Intel / Apple 芯片）。Windows/Linux ARM64 提供“后端＋浏览器”的便携包，不是 ARM64 原生桌面安装器。

升级前独立备份、完全退出旧应用和后端，然后安装新版本并保留原数据目录。新安装默认开启局域网且密钥保护关闭；升级保留已有网络与密钥设置，无需删除数据来启用新功能。绑定后双方可在任意一端使用原有界面。

## 验证范围

发布附件中的 `workspace-build-manifest.json` 记录源码提交、各平台构建与原生安装检查状态；`SHA256SUMS.txt` 用于校验下载内容。功能验证包括：双向绑定与持久化、开启密钥后的绑定、签名防重放、禁止越权配置与第三节点转发、全局分页、原设备写入、文档冲突、离线快照、远端文件票据及 Range、旧地址升级与真实浏览器协作。

候选包构建成功不代表每个实体系统的完整验收完成。Windows 原生 WebView 调试验收存在已知不稳定项；Ubuntu 22.04/24.04 安装与 macOS 原生运行结果分别记录，未测或失败均不记为通过。macOS 无 Apple 公证；不会把这个候选版本标为已解决 Gatekeeper 首次下载阻断。
